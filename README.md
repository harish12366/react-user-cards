# React User Cards

A simple React project to practice reusable components, props, and CSS Flexbox.

## Features
- Reusable UserCard component
- Passing data using props
- Displaying multiple user cards
- CSS Flexbox layout
- Card hover effects
- Box shadows and transitions
- Responsive design using media queries
- Custom button styling

## Technologies Used
- React
- JavaScript
- HTML5
- CSS3
- Vite

## Concepts Learned
- Functional Components
- JSX
- Props and Destructuring
- Component Reusability
- display: flex
- justify-content
- align-items
- align-self
- flex-start and flex-end
- CSS Hover Effects
- CSS Transitions
- Box Shadow
- Responsive Design
- Media Queries
